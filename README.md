## Known review concerns

- Current diagrams are overly vertical.
- The visual transaction should better show the request leaving and returning to the enterprise application as a complete cycle.
- Footer is crowded.
- Financial Services should remain in the primary header while the initial design-partner vertical remains open.
- The website currently appears to have regressed in visual hierarchy and enterprise presentation.
- Product truth and claim boundaries must remain unchanged during later visual corrections.
